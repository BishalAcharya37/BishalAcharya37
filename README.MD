### 🔧 What I've built

Production systems handling real-world complexity:

  audit logging on every critical action, soft deletes with full recovery
- **Auth systems** — JWT + OTP two-factor, trusted device management,

  idempotency keys, and dead-letter handling via Redis

  presigned URLs, atomic rollback on DB failure

- **E-commerce backend** — full order lifecycle, inventory management,
  payment integration, product catalogue at scale (Acharya Fancy Stores)

### 🎯 How I think about backend

- **Failure first** — what happens when step 2 fails after step 1 succeeds?
- **Concurrency** — two users, same resource, same millisecond — race condition?
- **Idempotency** — if this job runs twice, is the result the same?
- **Observability** — structured logs, audit trails, enough context to debug at 2am
- **Simplicity** — the boring solution that works beats the clever one that breaks
